# Danmaku Launcher Frontend

Interfaz gráfica para el lanzador de Touhou Project construida con Electron, React y Tailwind CSS.

## Desarrollo

Instalar dependencias:
```bash
npm install
```

Ejecutar en modo desarrollo:
```bash
npm run dev
```

Compilar para producción:
```bash
npm run build
```

Ejecutar pruebas unitarias:
```bash
npx tsx --test src/utils/launcherLogic.test.ts
```
